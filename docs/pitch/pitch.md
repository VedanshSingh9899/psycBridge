# psycBridge — Private Help, Perfect Doctor

> Uber + Urban Company for psychiatrists & psychologists. Privacy so deep, even family doesn't know if you don't want them to.

---

## The Problem
- India seeks help late — beyond borderline depression, often severe.
- Stigma + family fear stop first call. Photo ID, OTP, 10 questions = bounce.
- 5 famous doctors overbooked for months. 500 good young psychologists empty.
- Patient repeats trauma story to every new doctor. Referrals are cold — "go find him yourself."

## Our Promise
1. **3-year-old simple:** one tap to talk. Free first try. If it helps, you'll come back.
2. **Emotion first, data later:** docs ask what THEY need, when user is comfortable. We don't force forms.
3. **File travels, user doesn't:** brief slides doctor-to-doctor till perfect fit. Patient stays with one anchor.
4. **Doctors are free:** set own fee, time, style. Can leave platform anytime. No trap.
5. **No greed:** no paywall on first cry. Full money to workers initially. Community contribution for costs. Fee only after both sides love us.

## How It Works

### For Users
```
Open -> Talk Now -> Nickname (no login) -> Human in ~3 min
-> 8-10 min free chat/audio -> Same person offers follow-up?
-> Yes: book session + meds if needed -> Better with warm brief
```

- No OTP before help. Optional mobile later for neutral reminder.
- Alias mode, in-app call only, neutral SMS "Reminder 7pm", neutral billing "PB WELLNESS".
- One owner always. You never get passed around.

### For Doctors: The Care Graph
- Each doctor keeps a Circle of 5-10 trusted peers — clinical, neuro, psychiatrist, etc. We push cross-field friendship.
- A thinks "my friend will click better" -> sends Brief -> B sees masked preview -> **Yes / No / Suggest C**
- Until Yeah-Sure: user stays with A. File silently slides A->B->C. Max 3 hops.
- Rule: **who holds file, owns patient.** No limbo. A owns till B + patient both say yes, then B owns.
- Off-app referral allowed. If B joins later, A gets credit.

What B reads in 60 seconds to decide:
Presenting issue (5 lines) | Since when | Risk level | Scores if any | Meds tried | What helped / didn't | Language + gender preference

## Why This Balances Load
- Seniors full? Pass mild / vibe-mismatch to juniors with space + time.
- Juniors get warm, pre-briefed cases with "Dr. A sent you" trust. Start earning.
- Seniors keep severe / meds-heavy. Burnout drops, incomes even out.
- Status: Full / Space for 3. Cap 3 pending briefs per doc. Pausable.

## Money — Chanda First, Fee Later
- **Phase 1:** Direct UPI to doctor. Zero commission. Transparent monthly costs, voluntary contribution, split.
- **Phase 2 (after love):** Small disclosed fee both sides for discovery + tools.
- Never monetize first cry. Monetize follow-up care.

## Privacy by Design
Alias, no number exposed, stealth icon + PIN + blur, expiring chats, one-tap wipe, discreet prescription + plain delivery, break-glass only for self-harm with prior consent.
