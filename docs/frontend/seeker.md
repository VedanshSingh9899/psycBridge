# Seeker — `psycbridge.in` (future design reqs)

Who: 19-35, no private room, fear of family/call-log trace. Wants alias + audio-only + neutral traces.

## Flow (keep as-is, redesign skin only)

1. Splash: neutral `PB Wellness`, big Talk Now, small Talk Hours badge, SOS link, 1-line privacy.
2. Talk Now tap → auto alias e.g. QuietFox12 + lang Hi/En + optional gender-pref. No OTP/phone.
3. Triage (skippable, 10s): unsafe with self? Yes / No / Skip. Yes → SOS screen.
4. Queue: show humanity `X online, ~Y min, #pos`. Buttons: Wait / Book later / SOS. Outside 7-11pm → next slot + Notify me.
5. Session 8-10 min: chat + audio toggle, no video default. Wrap nudge at 8 min.
6. Post-help: Did this help 👍/👎. Optional cards only: reminder phone, save history, book follow-up. Never block.

## Design musts

- 3 taps to human, <2s join feel, poll/skeleton states, not spinners.
- Dark calm theme already in app — keep greens/purples, soft language, no clinical red except SOS.
- Stealth: neutral tab title, no `psych` word in UI/SMS/billing, blur in recents (later native).
- Hindi + English V1, audio-first copy for low literacy.

Out of scope V1: login wall, 10-question form, video pressure, payments.
