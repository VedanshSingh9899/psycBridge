# notes2 - psycBridge founder notes

> Uber / Urban Company for psychiatrists + psychologists, with privacy so deep even family doesn't know if user wants that.

## 1. Users are beyond borderline
- In India people come late, severe not mild.
- Entry must be stupid simple. Like a 3-year-old can try free. If it helps, he'll come again.
- No phone, no photo ID, no OTP, no 10 questions just to ask for help.
- One tap "Talk Now" -> nickname -> human waiting.

## 2. Follow-up is the real treatment
- First chat gives only ~2 days relief. After that need proper sessions + medicine.
- Docs need data for that stage, but that's THEIR problem. They ask only what they need, what user is comfortable with. Who are we to force a form? They are docs, they know.
- We monetize (when we do) only on follow-up, never on first cry.

## 3. Graph - file travels, user doesn't
- Each doc connected to 5-10 trusted people. Not just same field - clinical + neuro + psychiatrist etc. We push them to befriend outside field too.
- If A feels "my friend can do better / click better", A sends brief, B reads and says Yes / No / "C is perfect".
- File slides node to node till someone says "yeah sure I'll take him".
- User stays with one anchor, no here-there. Only final yes meets patient.
- Until we get yeah-sure one, we do NOT move user. Just pass files, read and pass.
- Day by day this makes network dense and service better automatically.

## 4. Ownership rule
- Till case is given or surely passed, it's his domain / responsibility. Simple.
- Who has file, owns patient. No limbo.
- A owns till B says yes + patient says yes. Then B owns. Always one owner.

## 5. Load balancing
- This will reduce work for overworked psychologists and give chance to those earning less.
- Seniors drowning pass mild / fit-mismatch cases to juniors with time.
- Juniors get warm trusted cases, start earning. Seniors keep severe.

## 6. Brief file
- Docs make a brief so next doc doesn't repeat hours of same process.
- Patient doesn't re-live trauma.
- B can decide yes/no in 1 min.

## 7. Full freedom
- Docs free inside + outside. If they want to leave platform and consult privately, they can.
- We figure out model as we go. No trap.

## 8. Payments - no greed
- No payment system initially. Full money to workers.
- Then ask them to contribute as much we need and divide costs.
- Only after both doctors + consumers are onboard and stuck, add small fee both sides.

## 9. Team
- Tech (you) + psych student friend (domain) + business friend to join soon.
